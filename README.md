# BorderWise : International Tourist Compliance & Restriction Matrix

**BorderWise** is a pre-flight border, customs, and cultural rulebook web application that compares a traveler's home country against their destination. Everyday OTC medicines, kitchen spices, and normal habits at home can trigger heavy fines or detention abroad, BorderWise surfaces those differences before you fly.

## Key Features
- **Origin vs. Destination Audit:** Compare country corridors (such as India → Singapore, UAE, Japan, and Thailand) with severity ratings and penalty breakdowns.
- **Home vs. Destination Reality Check:** Side-by-side comparisons of everyday habits at home versus strict enforcement abroad.
- **Live Item & Category Search:** Filter rules across medications, prohibited items, public laws, and cultural etiquette.
- **AI Customs Lookup:** Ask about specific medicine brands or edge cases.
- **Traveler Utilities:** Printable airport declaration pass, doctor prescription cover letter generator, and layover transit screening checks.
- **Editorial Themes:** Switch seamlessly between **Paper**, **Warm Dusk**, and **Obsidian** reading modes.

## Tech Stack
- HTML5, Tailwind CSS, and Vanilla JavaScript (single-file architecture)
- Gemini API integration for custom item compliance lookups
